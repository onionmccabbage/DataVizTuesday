## Outline a data narrative based on a provided dataset or scenario

Until 12:10

Spend a bit of time inventing one or more personas to whom your data story will be presented

Pick a data set from these or some other resources. Create an outline of how this dataset could tell a story
- There is no expectation to actually implement the data story
- Decide on target audience/stakeholders
- Outline the questions you would like to find out from the data
- Describe or draw how you would like to present the data story
